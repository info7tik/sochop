# APPLICATION

## DESCRIPTION

A mobile app that lets 3–4 people share multiple shopping lists. Every user of the app sees and edits the same lists. Anyone can add items, see what is still needed, and mark items as bought while in the store. The app is built for a small trusted circle rather than the public.

## ARCHITECTURE

- **UI**: mobile app for phones
- **Backend**: API and file storage holding the shared shopping lists and its items
