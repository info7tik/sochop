# APPLICATION

## DESCRIPTION

A mobile app that lets a small group of 3–4 people share one shopping list. Anyone in the group can add items, see what is still needed, and mark items as bought while in the store. Each item shows who added it and who checked it off. The group uses the app on its own phones, so it is built for a small trusted circle rather than the public.

## NEXT USER STORIES

### Retrieve an existing shopping list
As a member of the group, I want to open the shared shopping list so that I can see what we already need. The list appears as soon as I open the app on my phone. Items show who added them and whether they are already checked off. I can see the list even before I add anything new.

### Add an item to the list
As a member of the group, I want to add an item to the shared list so that everyone knows what we need. I
type the name of the item and it appears at the bottom of the list. The item shows my name as the person w
ho added it. The list updates right away on my phone.

### Check off a bought item
As a shopper, I want to mark an item as bought so that others know it is already in the cart. I tap the item and it is shown as checked, with my name next to it. Checked items stay visible but are clearly separated from the items still needed.

### Choose my name on this phone
As a member of the group, I want to set my name once on my phone so that the items I add and check off are attributed to me. The name is remembered the next time I open the app. I can change it later if needed.

### Remove an item
As a member of the group, I want to remove an item so that the list stays accurate. I can delete an item I added by mistake or one we no longer need. The removal is visible to everyone in the group.

### See changes from others
As a member of the group, I want to see changes made by others without reloading so that the list is always up to date. When someone adds, checks off or removes an item, I see it on my phone within a few seconds. I can see what is still needed before I go to the store.
