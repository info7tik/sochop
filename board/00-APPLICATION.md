# APPLICATION

## DESCRIPTION

A mobile app that lets 3–4 people share multiple shopping lists. Every user of the app sees and edits the lists. Anyone can add items, see what is still needed, and mark items as bought while in the store. The app is built for a small trusted circle rather than the public.

## NEXT USER STORIES

### Open the shared shopping list
As a user of the app, I want to open the shared shopping list so that I can see what we still need. Everyone sees the same list, so there is nothing to set up. Items that are already checked off are shown as such. When nothing has been added yet, the app shows an empty list with a clear invitation to add the first item.

### Add an item to the list
As a user of the app, I want to add an item to the shared list so that everyone knows what we need. I type the name of the item and it appears at the bottom of the list. An empty name is not added. The new item is visible to everyone who uses the app.

### Check off a bought item
As a shopper, I want to mark an item as bought so that others know it is already in the cart. I tap the item and it is shown as checked. Checked items stay visible but are separated from the items still needed. I can tap a checked item again to mark it as needed once more.
